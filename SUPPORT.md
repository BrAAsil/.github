# Support

## Getting Help

- **Discord**: Join our community at [discord.braasil.com](https://discord.braasil.com) for questions and discussions
- **GitHub Issues**: Search [existing issues](https://github.com/braasil) before opening a new one
- **GitHub Discussions**: Use the Discussions tab in the relevant repository for general questions

## Reporting Bugs

Use the **Bug Report** issue template in the relevant repository. Include steps to reproduce, expected behavior, and actual behavior.

## Feature Requests

Use the **Feature Request** issue template. Describe the problem you're trying to solve and your proposed solution.

## Security Issues

See [SECURITY.md](SECURITY.md) for reporting security vulnerabilities. Do not use public issues for security reports.
